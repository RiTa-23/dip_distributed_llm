# 役割分担

4人チーム(2人はハッカソン開発初心者)。

| 担当 | 役割 | 作業内容 |
|---|---|---|
| ①コア分散基盤 | 最難関。経験者 | WASM版llama.cpp RPCビルド・移植、WebRTC DataChannel向けパッチ、WebGPU有効化 |
| ②コーディネータ/インフラ | Honoサーバ | WebSocket接続管理、WebRTCシグナリング中継、静的配信(GGUF含む) |
| ③フロント(チャットUI) | 初心者 | requester画面: プロンプト入力、生成結果ストリーミング表示、ピア一覧 |
| ④フロント(貢献側UI) | 初心者 | peer画面: 接続処理、貢献状況表示、演出 |

## 進め方

- 初日にWebSocketメッセージ形式(`api-contract.md`)を先に確定 → ②③④は並行開発可能
- ③④は②完成前でもモック(`implementation-spec.md`参照)で画面実装を先行
- ①が最大リスク要因。1日目夕方に「最低限動くか」を判定するチェックポイントを設け、ダメならスコープを削減
